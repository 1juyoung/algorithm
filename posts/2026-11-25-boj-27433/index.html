팩토리얼 2

0부터 20까지의 정수 N이 주어질 때 N!을 구하는 문제야.

문제 보러 가기 ↗
푸는 방법

이 문제는 재귀 함수나 반복문을 사용해 팩토리얼을 계산하는 문제야.

내 풀이

my solutionpython
1def fac(t):
2    if t <= 1:
3        return 1
4
5    return t * fac(t-1)
6
7
8n = int(input())
9print(fac(n))

내 풀이는?

✓ 방향 맞음

맞아, 재귀 함수로 깔끔하게 잘 풀었어.

시간 복잡도 최선
O(N)
내 공간O(N)
최선 공간O(1)

N 최대 20으로 연산 횟수가 매우 적어 재귀 호출에 따른 스택 공간은 O(N)이지만 시간과 공간 모두 넉넉하게 통과해.

잘한 점

  • 팩토리얼 정의에 맞게 재귀 함수를 간결하게 잘 짰어.
  • 0!이 입력될 때의 기저 조건(t <= 1)을 잘 처리했어.
