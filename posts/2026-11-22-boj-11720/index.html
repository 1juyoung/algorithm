숫자의 합

공백 없이 붙어 있는 숫자 N개(1 ≤ N ≤ 100)를 한 글자씩 더한 합을 구해.

문제 보러 가기 ↗

내 풀이

my solutionpython
1n = int(input())
2nums = str(input())
3answer = 0
4for i in nums:
5    answer += int(i)
6print(answer)
시간 복잡도 개선 가능
O(N)
내 공간O(N)
최선 공간O(N)

숫자 문자열을 한 번 훑으면서 더하니까 O(N)이야. N이 최대 100이라 연산은 100번 정도라 아주 여유로워.

내 풀이 요약

숫자 문자열을 한 글자씩 돌면서 int로 바꿔 answer에 더했어.

잘한 점

  • 문자열을 한 글자씩 돌며 숫자로 바꾸는 흐름이 정확해
  • 입력 크기에 맞는 O(N) 풀이야

코멘트

str(input())은 필요 없어

input()은 이미 문자열을 돌려줘서 str()로 한 번 더 감쌀 필요가 없어.

쓰지 않는 변수 n

개수 N은 문자열 길이로 알 수 있어서 따로 저장하지 않아도 돼. 첫 줄은 input()으로 읽고 버려도 충분해.

이 문제에서 드러난 약점

문법 · 내장 함수sum과 map으로 한 줄에 끝나는 계산을 반복문으로 직접 했어.

더 나은 풀이

숫자 문자열의 각 글자를 map(int, ...)으로 바꾸고 sum으로 바로 더해.

better · O(N)python
1input()
2print(sum(map(int, input())))
매일 자정, 그날 푼 풀이를 자동으로 분석해서 올려요.
