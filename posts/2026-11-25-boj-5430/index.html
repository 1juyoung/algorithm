AC

수행할 함수 문자열(R: 뒤집기, D: 버리기)과 초기 배열이 주어질 때 최종 연산 결과 또는 에러 여부를 구하는 문제야.

문제 보러 가기 ↗
푸는 방법

이 문제는 덱(deque)과 뒤집힘 상태를 나타내는 플래그로 푸는 문제야. 매번 실제로 뒤집지 않고 상태 플래그를 반전시킨 뒤, 뒤집힌 상태면 pop(), 원래 상태면 popleft()를 수행하고 마지막에 필요할 때만 뒤집는 것이 핵심이야.

내 풀이

my solutionpython
 1from collections import deque
 2n = int(input())
 3out = []
 4
 5for _ in range(n):
 6    p = input().strip()
 7    t = int(input())
 8    s = input().strip()
 9
10    l = deque(s[1:-1].split(',')) if t > 0 else deque()
11    rev = False  # 지금 뒤집힌 상태인지만 기억
12    error = False
13
14    for c in p:
15        if c == 'R':
16            rev = not rev
17        else:
18            if not l:
19                error = True
20                break
21            if rev:
22                l.pop()  # 뒤집힌 상태면 '앞'은 실제로는 뒤쪽
23            else:
24                l.popleft()
25
26    if error:
27        out.append('error')
28    else:
29        if rev:
30            l.reverse()  # 마지막에 한 번만 실제로 뒤집기
31        out.append('[' + ','.join(l) + ']')
32
33print('\n'.join(out))

내 풀이는?

✓ 방향 맞음

맞아, R 연산을 매번 수행하지 않고 불리언 플래그와 덱(deque)을 조합해서 아주 정석적으로 풀었어.

시간 복잡도 최선
O(|p| + n)
내 공간O(n)
최선 공간O(n)

각 테스트 케이스마다 함수 문자열 p를 순회하면서 O(1) 덱 연산을 수행하고, 마지막에 최대 n개의 원소를 출력 문자열로 만들어. 전체 테스트 케이스의 |p|와 n의 합이 최대 700,000이므로 총 연산 횟수는 100만 번 안팎으로 제한 시간(1초) 내에 매우 여유롭게 통과해.

잘한 점

  • 매번 배열을 뒤집지 않고 rev 플래그로 O(1)에 방향을 전환한 점
  • deque의 popleft()와 pop()을 상황에 맞춰 활용해 버리기 연산을 O(1)에 처리한 점
  • t == 0인 예외 상황에서 빈 deque를 안전하게 생성해 빈 문자열 파싱 오류를 방지한 점
