재귀의 귀재

주어진 문자열이 팰린드롬인지 판별하고 재귀 함수 호출 횟수를 구하는 문제야. (테스트케이스 T 최대 1,000, 문자열 길이 최대 1,000)

문제 보러 가기 ↗
푸는 방법

이 문제는 재귀 함수를 이용해 양 끝에서부터 문자를 비교하며 팰린드롬 여부를 판별하고, 호출 횟수를 카운트하는 문제야.

내 풀이

my solutionpython
 1count = 0
 2
 3def recursion(s, l, r):
 4    global count
 5    count += 1
 6    if l >= r:
 7        return print(f'1 {count}')
 8    elif s[l] != s[r]:
 9        return print(f'0 {count}')
10    else:
11        return recursion(s, l + 1, r - 1)
12
13
14def isPalindrome(s):
15    return recursion(s, 0, len(s) - 1)
16
17n = int(input())  # 테스트 케이스 개수
18
19for i in range(n):
20    count = 0
21    st = input()
22    isPalindrome(st)

✓ 방향 맞음

맞아, 문제에서 제시한 재귀 구조를 그대로 구현해서 풀었어.

시간 복잡도 최선
O(T * |S|)
내 공간O(|S|)
최선 공간O(|S|)

문자열 길이의 절반만큼 재귀 호출을 하므로 각 테스트케이스마다 O(|S|)의 시간이 걸리고, 전체 테스트케이스 T개를 곱하면 최대 약 1,000 * 500 = 50만 번의 연산으로 충분히 통과해.

잘한 점

  • 문제에서 요구하는 재귀 함수 구조와 로직을 정확하게 코드로 구현했어.
  • 테스트케이스마다 전역 변수 count를 0으로 잘 초기화했어.
