🐜 기적의 매매법 🐜

현금과 14일간 주가가 주어질 때, 매일 최대한 사는 준현과 3일 연속 하락에 사고 3일 연속 상승에 파는 성민 중 마지막 날 자산이 큰 사람을 구해.

문제 보러 가기 ↗

내 풀이

my solutionpython
 1n = int(input())
 2nums = list(map(int, input().split()))
 3
 4answer = [0, 0]
 5
 6anStr = ''
 7# 연속 3번 하락 또는 상승인지 카운트할 애
 8count = {-1: 0, 1: 0}
 9
10# 여기서 키 0의 값은 현금을 말함
11# 다른 숫자는 매입한 값과 매수의 양
12jh = {0: n}
13sm = {0: n}
14
15for idx, i in enumerate(nums):
16
17    if idx != 0:
18        if nums[idx - 1] < i:
19            count[1] += 1
20            count[-1] = 0
21        elif nums[idx - 1] > i:
22            count[-1] += 1
23            count[1] = 0
24        else:
25            count[-1] = 0
26            count[1] = 0
27
28    if i <= n:
29        while jh[0] >= i:
30            jh[0] = jh[0] - i
31            jh[i] = jh.get(i, 0) + 1
32
33    if count[-1] >= 3:
34        if i <= sm[0]:
35            while sm[0] >= i:
36                sm[0] = sm[0] - i
37                sm[i] = sm.get(i, 0) + 1
38
39    if count[1] >= 3:
40        for j in sm.keys():
41            if j == 0:
42                continue
43            sm[0] = sm[0] + (i * sm[j])
44            sm[j] = 0
45
46for a, k in sm.items():
47    if a != 0:
48        answer[0] += k * nums[-1]
49
50for l, q in jh.items():
51    if l != 0:
52        answer[1] += q * nums[-1]
53# sm
54answer[0] = answer[0] + sm[0]
55
56# jh
57answer[1] = answer[1] + jh[0]
58
59if answer[0] > answer[1]:
60    anStr = "TIMING"
61elif answer[0] < answer[1]:

66print(anStr)
시간 복잡도 개선 가능
O(D·C)⟶O(D)
내 공간O(D)
최선 공간O(D)

주식을 while로 한 주씩 사서 하루에 최대 현금 C번(C ≤ 1000) 반복해. D가 14일이라 최대 1만 4천 번 정도라 통과는 하지만, // 와 %를 쓰면 하루 한 번 계산으로 끝나.

내 풀이 요약

상승·하락 연속 횟수를 먼저 세고, 준현은 매일, 성민은 3일 이상 연속 하락일 때 한 주씩 사고 3일 이상 연속 상승이면 전부 팔았어.

잘한 점

  • 오늘의 상승·하락을 먼저 세고 판단하는 순서가 정확해
  • 방향이 바뀌면 반대 횟수를 0으로 되돌려서 연속을 제대로 판정했어
  • >= 3으로 4일째 연속에도 다시 사게 처리했어

코멘트

한 주씩 사는 반복문

살 수 있는 주식 수는 현금 // 가격, 남는 돈은 현금 % 가격으로 한 번에 구할 수 있어.

산 가격별로 저장할 필요 없어

필요한 건 현금과 보유 주식 수뿐이라 딕셔너리 대신 변수 두 개면 충분해.

겹치는 조건

if i <= n, if i <= sm[0]은 바로 아래 while 조건과 겹쳐서 지워도 돼.

이 문제에서 드러난 약점

자료구조 선택주식 수만 있으면 되는데 산 가격별 딕셔너리를 써서 코드가 복잡해졌어.

더 나은 풀이

현금과 주식 수 두 변수로 관리하고, 매수는 // 와 %로 한 번에 계산해.

better · O(D)python
 1cash = int(input())
 2prices = list(map(int, input().split()))
 3
 4jh_cash, jh_stock = cash, 0
 5sm_cash, sm_stock = cash, 0
 6up = down = 0
 7
 8for i, price in enumerate(prices):
 9    if i > 0:
10        if price > prices[i - 1]:
11            up, down = up + 1, 0
12        elif price < prices[i - 1]:
13            up, down = 0, down + 1
14        else:
15            up = down = 0
16
17    jh_stock += jh_cash // price  # 준현: 살 수 있으면 매일 최대한
18    jh_cash %= price
19
20    if down >= 3:  # 성민: 3일 이상 연속 하락이면 전량 매수
21        sm_stock += sm_cash // price
22        sm_cash %= price
23    elif up >= 3:  # 3일 이상 연속 상승이면 전량 매도
24        sm_cash += sm_stock * price
25        sm_stock = 0
26
27last = prices[-1]
28jh = jh_cash + jh_stock * last
29sm = sm_cash + sm_stock * last
30print("BNP" if jh > sm else "TIMING" if sm > jh else "SAMESAME")
